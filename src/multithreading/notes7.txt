******************  wait    *************************
two thread can communicate with each other by using wait ,notify,notify all method

the thread which is expecting updation is responsible to call wait method then, immediately will enter into waiting state

the thread which is responsible to perform updation, after performing updation it is responsible notify method,
 then waiting thread will get notification and continue it's execution with those updated item

 wait,notify,notifyall is present in the object class and not in the thread class

wait,notify,notifyall is only applicable to thread

=================
wait ,notify,notify all methods present in the object class but not in thread class because thread can call this method
on any java object
===================

to call wait,notify,notify all methods on any object, thread should be owner of that object i.e the thread should
has lock of that object i.e the thread should be inside synchronized area

if not then the exception will occur named as IllegalMonitorStateException

hence we can call wait,notify,notify all methods only from synchronized area otherwise we will get run time Exception
saying IllegalMonitorStateException

@@ if a thread calls wait method on any object it immediately releases the lock of that particular object and enter
into waiting state

if a thread calls notify method on any object it releases lock of that object may not immediately except wait,notify,
notifyall there is no other method where thread releases the lock

yeild,join,sleep ===> thread doesn't releases the lock
wait,notify,notifyall ===> releases the lock

which of the following is valid
1) if a thread calls wait method immediately it will enter into waiting state without releasing any lock ---> INVALID
2) if a thread calls wait method it releases lock of that object but may not immediately ---> INVALID
3) if a thread calls wait method on any object if releases all lock acquired by that thread and immediately
enter into waiting state -----------------> INVALID
4) if a thread calls wait method on any object it immediately releases lock of that particular object and enter into
waiting state ----->VALID
5) if a thread calls notify methos it immediately releases lock of that particular object ---> INVALID
6) if a thread calls notify method on any object it releases lock of that object but may not immediately ---> VALID

wait method calls
public final void wait() --> throws InterupttedException
public final native void wait(long millisecond) --> throws InterupttedException
public final void wait(long millisecond,int nanosecond) --> throws InterupttedException

notify method calls
public final native void notify()
public final native voi notifyAll()

Note : every wait method throws InterupttedException which is checked Exception hence whenever we are using wait
method compulsory we should handle this InterupttedException either by try catch or throws keyword . otherwise we will
get compile time error
