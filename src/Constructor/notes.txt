**** Rules for the constructor  *****

1) name of the constructor and class needs to be same
2) return type of constructor is not applicable for the constructor not even void is not applicable
class test{
    void test(){

    }
}
---> compiler treats it as method and not as constructor

3) only public,private,default and protected is allowed as the access modifier in the constructor and
final,static strict, native, synchronized are not allowed then the compile time error will occur

4) constructor can have the private access modifier but it cannot be accessed by the other class
by making the constructor private we are making class as singletone class

********************** Default constructor *****************************

** every class in java including abstract class also contain the default constructor

** every class in java contain constructor it may be default or parameterized constructor but it cannot be both constructor

** if you are writing the parameterized constructor then the default constructor will not come in the particular class

** the access modifier of the default constructor is same as the access modifier of the class
if class is public then ---> public constructor
default ----> default
for just of this is applicable

** default constructor contain just one line
public test{
    public test(){
    super(); <---- just this line is present in it
    }
}

** it is no-argumment call to super class constructor

************** super() & this() ****************************

the first line in the constructor needs to be always super() or this() if you are not writing then compiler will
always take it by default

we can't take super and this in one constructor

1) we can use only inside constructor
2) we should use only on first line
3) we can use only one simultaneously but not the both

**************************** super and this **************************************
class parent{
    String s="Parent class";
}
public class C4_Super_This extends parent {
    public void meth(){
        String s="Child class";

        System.out.println(s);
        System.out.println(this.s);
        System.out.println(super.s);
    }
    public static void main(String[] args) {
        meth();    <--------------- here will be error because in the static area we are calling the super and this
    }
}
error ==> non static variable cannot be reference from a static area

// so here we cannot use the super and this because the area is the staic so super and this will not work there
// so if we wants to use the super then we have to write those method in non-static area

*********************************** Constructor overriding **********************************************

******************************* absract class & interface constructor ****************

instantiation happens on declaration only so we cannot apply constructor inside the interface
